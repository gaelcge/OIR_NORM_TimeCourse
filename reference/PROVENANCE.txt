REFERENCE DATA USED BY THIS ANALYSIS
====================================

None of these files are committed. They are cached beside the data on the
cluster and the scripts read them through DATA_DIR. Checksums were taken from
the copies that the published analysis actually read, on 2026-09-29, so a
future re-run can confirm it is using the same release rather than whatever the
source currently serves.

Recorded here rather than in a script comment because MSigDB publishes a
release string but the file itself carries no version once downloaded, and
re-downloading a "senescence" gene set under a finished figure would change a
result with no visible cause. Pin; do not refresh.

3. Custom senescence gene sets - NOT AVAILABLE
---------------------------------------------------------------------------
Used by   1_timecourse_p5_p17/04_gsva_senescence.R
Three gene sets are imported from .gmx files belonging to another member of the
laboratory and are combined with the MSigDB collections above before GSVA runs:

  MALLETTE_SENESCENCE_UP
  GLOBAL_SENESCENCE_LITERATURE_CURATED   (from ..._2020.gmx)
  SAWCHYN_UNBIASED_UP                    (from ..._v4.gmx)

They live under another user's project directory and are **not readable by the
author of this repository** (permission denied, checked 2026-09-29). They are
therefore not committed, not checksummed, and their contents are not recorded
here.

Consequence, stated plainly: the GSVA step cannot be reproduced from this
repository as it stands, and neither can the functional differential-expression
step that reads its output. The MSigDB part of the collection is fully
specified above; the three custom sets are not. See METHODS_CHOICES.md in
1_timecourse_p5_p17 for how this is reported.
